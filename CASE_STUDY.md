# Signal Garden — Case Study

## Problem / Problemă
Many attention games depend on colour, speed, precise pointer movement or sound alone.

## Decision / Decizie
Every essential cue is redundant: symbol, word, colour, pattern and optional speech. Relaxed mode removes time pressure; single-switch scanning supports limited motor control.

## Implementation / Implementare
Static HTML/CSS/JavaScript, localStorage persistence, offline service worker, bilingual UI, campaign, adaptive difficulty, Mistake Review and exportable reports.

## Outcome / Rezultat
A privacy-friendly cognitive game requiring no account or backend. Measured Lighthouse results will be added only after a reproducible audit.

## Limitations / Limitări
Assistive-technology and translation validation with real users remains necessary.
